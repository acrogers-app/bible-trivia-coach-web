# Learn lesson standard (DRAFT for Allen's review)

This standard helps us write and evaluate lessons. Passing the validator, or a learner
passing a check, does not prove a lesson works. It shows the lesson meets our rules and
that one learner answered these questions on one day.

Use it with [REVIEW_CHECKLIST.md](REVIEW_CHECKLIST.md) for every lesson.

## 1. The reusable teaching pattern (any subject)

**Outcomes → source material → explanation → optional deeper context → practice → summary**

| Step | Purpose |
|------|---------|
| Outcomes | 2–3 things the learner should be able to do afterward. Written first. |
| Source material | The primary text the lesson is about. Shown before anyone's explanation. |
| Key term or concept (conditional) | Only when one term or idea unlocks the lesson. |
| Explanation | Plain-language teaching, clearly labelled as explanation, not source. |
| Deeper context (optional) | Background or where views differ. |
| Practice | Questions that each test an outcome. |
| Summary | Result, 2–3 key points, optional reflection. |

## 2. Bible-specific choices (this app)

| Pattern step | In Learn |
|--------------|----------|
| Source material | Scripture, World English Bible, with **Read** and (planned) **Listen** |
| Key term | **Word study** (Greek or Hebrew), only when it genuinely helps |
| Explanation | "Explanation · not Scripture" |
| Deeper context | "Go deeper", marked `viewsDiffer` when Christians disagree |
| Summary | Includes an optional, untracked reflection |

## 3. Rules

**Outcomes**
- Write 2–3 measurable outcomes before drafting. Use verbs a learner can show: *explain,
  identify, compare, find in the text*. Avoid *know, understand, appreciate*.
- Map every section and every check question to at least one outcome. A question that
  maps to nothing gets cut. Never add questions just to reach a count.

**Sources and claims**
- Keep three kinds of content apart: **source text** (Scripture), **explanation or
  inference** (ours), and **contested interpretation** (labelled, with views described
  fairly and not ranked).
- Every quotation is checked word-for-word against WEB. Every other factual claim (a
  lexicon definition, a historical note) names a traceable source.

**Word studies (conditional)**
- Include one only when it helps reach an outcome.
- Separate the **lexicon gloss** (the dictionary's general range, e.g. "favor") from
  the **contextual meaning** (what the word does in this passage). Say which is which.
- Don't argue a meaning from the root alone, and don't imply that a Hebrew word and a
  Greek word mean exactly the same thing because one often translates the other.
- Cite a public-domain lexicon (e.g. Strong's, Thayer's, BDB) with its entry number.
- For non-Bible subjects, use a key-term or concept section instead.

**Practice and the pass mark**
- Each question has exactly one defensible answer and plausible, clearly wrong distractors.
- The current pass rule (5 questions, 4 correct) is a **product policy we are evaluating**,
  not proof of mastery. Scores depend on question quality and how well the questions
  cover the outcomes.
- Fewer suitable approved questions than planned is a content gap to fill, never a reason
  to lower the bar.

**Accessibility and usability**
- Readable at large Dynamic Type sizes, VoiceOver labels on every control, 44pt targets,
  and colour never the only signal. Read and Listen both work without an account or download.

**Isolation and privacy (unchanged)**
- Learn checks have no XP, streak, Path, Daily Challenge, analytics, best-score or
  missed-question effects. Progress stays on the device.
- Nothing in this standard authorises collecting learner data in the app. Pilot feedback
  is gathered outside the app, voluntarily, with consent, minimal personal detail and no
  children's data without a parent, consistent with the app's privacy policy.

## 4. Pilot and evaluation
- Test each lesson with a few intended learners (think-aloud: they read and talk while
  you watch; you don't help).
- Check immediate understanding with the lesson's check. Where feasible, check retention
  about a week later with **new, comparable** questions on the same outcomes.
- Record issues and revisions in the lesson's review sheet.
- A small pilot is **diagnostic**: it finds confusing wording, bad questions and gaps.
  It is not evidence that the lesson or method is better than another.
